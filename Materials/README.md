# Documentation and media

The brand assets, use-case videos, posters, and design illustrations in this
folder are shared with the iOS SDK. The installation and usage guides are adapted
for the macOS SDK.

- [Installation guide](./installation.md): SwiftPM, CocoaPods, dependency packaging,
  and host application configuration.
- [Usage guide](./usage.md): camera capture, external video, generation, rendering,
  lifecycle, and diagnostics.
- `images/brand/`: shared XmaxSDK branding and design concepts.
- `images/use-cases/` and `videos/use-cases/`: shared model demonstration media.
  These illustrate model use cases, not a list of implemented macOS input APIs.
- `images/why/`: shared product illustrations.
- `images/xlab/`: screenshots and recordings of the **iOS XLab application**,
  retained from the source materials as design references. They do not show the
  macOS example. The native macOS example is in [Examples/XLab](../Examples/XLab).

Live Photo and trajectory demonstration media are retained as shared model
materials. The current macOS SDK does not expose built-in static-image input,
file-video input, or mouse trajectory interaction.
